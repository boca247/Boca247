# BOCA 24/7 — REAL 3D

Esta versión reemplaza la portada por un portal xeneize dinámico, responsive y con profundidad 3D mediante CSS/JS sin dependencias externas.

Incluye:
- portada hero con imagen de Los Bosteros de Tucumán;
- efecto 3D/parallax en tarjetas;
- próximo partido y contador;
- noticias cargadas desde noticias.json;
- resultados y agenda desde partidos.json;
- bloque de streaming;
- bloque El Hincha;
- navegación y responsive.

Las noticias/partidos del 5 de septiembre de 2026 fueron actualizados a partir de fuentes públicas consultadas ese día. Antes de publicar una noticia nueva, revisar su fuente.

Para Vercel: reemplazar el contenido del repositorio por esta carpeta y hacer push. No hace falta instalar Node ni ejecutar un build.
